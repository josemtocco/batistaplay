# Batista Play → M3U para SS IPTV

Gerador automático de playlist M3U a partir do Batista Play.

## Recursos
- Atualização automática a cada 6 horas.
- Descoberta de páginas e streams.
- Teste individual dos streams.
- Somente streams ativos entram na M3U.
- Novos streams são acrescentados automaticamente.
- Streams que deixam de responder são removidos.
- Nome do canal em `tvg-name`.
- Categorias em `group-title`.
- `tvg-country="BR"` e `tvg-language="Portuguese"`.
- Todos os arquivos gerados ficam na raiz do repositório.

## Execução manual
Em GitHub: Actions → Atualizar Batista Play M3U → Run workflow.
